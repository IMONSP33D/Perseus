# example (addon template)

Copy `perseus/addons/_example/` to `perseus/addons/<your_name>/`, rename `example` throughout,
and restart Perseus. The addon guide in `docs/addons.md` walks through every file.

What a user of your addon needs to know goes here: the service it talks to, how to get a key,
what the `[<your_name>]` settings in `Config/tooling.toml` mean, and what the model can and can't
do with it. The main README's addon table links to this file.
